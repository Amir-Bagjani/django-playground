# مرحله‌ی ۲ — ساخت MySQL Schema (DDL)

طراحی مرحله‌ی قبل را حالا به **DDL واقعی MySQL** تبدیل کن. این کد روی یک دیتابیس آزمایشی واقعی اجرا می‌شود.

## خواسته‌ها

یک اسکریپت SQL بنویس که:

1. جدول `rooms` را با کلید اصلی بسازد و شماره/نام اتاق و ظرفیت را نگه دارد.
2. جدول `bookings` را با کلید اصلی بسازد و نام مهمان، تاریخ ورود، تاریخ خروج و `room_id` را نگه دارد.
3. در جدول `bookings` یک **کلید خارجی واقعی** (`FOREIGN KEY`) روی `room_id` به `rooms(id)` تعریف کند و این ستون `NOT NULL` باشد.
4. حداقل **دو اتاق** و **دو رزرو** با `INSERT` درج کند.

## نکته‌های فنی

- می‌توانی چند دستور را پشت سر هم بنویسی و هر کدام را با `;` تمام کنی.
- برای تاریخ‌ها از نوع `DATE` استفاده کن.
- برای ظرفیت از نوع عددی بدون علامت (مثلاً `INT UNSIGNED`) یا `INT` استفاده کن.
- ترتیب مهم است: اول `rooms` ساخته شود، بعد `bookings`.

## یادداشت مهندسی (بازبینی دستی)

در یک کامنت بالای کد توضیح بده چرا این قیدها و این نوع‌های ستون را انتخاب کردی. این بخش دستی بررسی می‌شود و در قبولی خودکار اثری ندارد.

**قبولی خودکار:** اسکریپت روی MySQL واقعی اجرا می‌شود، سپس ساختار Schema (جدول‌ها، کلید اصلی، کلید خارجی، NOT NULL) و تعداد ردیف‌های درج‌شده بررسی می‌شوند — نه متن کد.
