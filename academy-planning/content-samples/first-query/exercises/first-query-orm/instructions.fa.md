# تمرین ORM: همان نتیجه با QuerySet

مدل `Product` از قبل در محیط اجرا بارگذاری شده است و همان داده‌ی تمرین SQL را می‌خواند. کافی است روی `Product.objects` کار کنی؛ نیازی به `import` نیست.

کد پایتونی بنویس که:

1. محصولات موجود (`in_stock=True`) را انتخاب کند.
2. فقط فیلدهای `name` و `price` را بگیرد.
3. بر اساس `price` به‌صورت **نزولی** مرتب کند.
4. نتیجه را در متغیر `result` بگذارد.

**قبولی:** کد در یک پروسه‌ی کنترل‌شده‌ی Django روی همان دیتابیس اجرا می‌شود؛ `result` باید همان سطرها، ستون‌ها و ترتیب تمرین SQL را بدهد. اگر کد خطا بدهد، همان خطا (Traceback) نمایش داده می‌شود و قبول نمی‌شود.
