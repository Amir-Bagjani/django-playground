# تمرین SQL: خواندن محصولات موجود

جدول `products` با ستون‌های `id`، `name`، `price` و `in_stock` در اختیار توست و چند سطر نمونه در آن درج شده است.

یک دستور `SELECT` بنویس که:

1. فقط محصولاتی را برگرداند که `in_stock = 1` هستند.
2. فقط ستون‌های `name` و `price` را برگرداند.
3. نتیجه را بر اساس `price` به‌صورت **نزولی** مرتب کند.

**قبولی:** پرس‌وجو روی همان جدول واقعی اجرا می‌شود و نتیجه باید دقیقاً همان سطرها و ستون‌ها و ترتیب را بدهد. مقدار ثابت و از پیش نوشته‌شده قبول نیست.
