# تمرین کاربردی: SQL و Referential Integrity

در MySQL جداول `customers` و `orders` را طراحی کن؛ هر سفارش باید Customer معتبر و `total` مثبت داشته باشد. داده اولیه شامل ۲ مشتری است. SQL را خودت بنویس و سپس تلاش کن یک سفارش برای Customer ناموجود ثبت کنی.

**قبولی:** ساختار شامل Foreign Key واقعی و NOT NULL باشد؛ سفارش نامعتبر رد شود و سفارش معتبر درج شود. نام Constraint آزاد است. جدول‌ها باید InnoDB باشند.
