# تمرین مقدماتی: تعریف مدل سفارش

مدل `Customer` از قبل در محیط تمرین وجود دارد. خودت مدل `Order` را بنویس که فیلد `customer` از نوع ForeignKey اجباری باشد و حذف مشتریِ دارای سفارش را متوقف کند. فیلد `total` باید DecimalField با دقت مناسب باشد.

**قبولی:** Django system check و Migration موفق؛ ارتباط اجباری و قانون جلوگیری از حذف توسط سناریوهای واقعی اثبات شود. از نام و نوع فیلد موردنیاز پیروی کن، ولی ترتیب نوشتن فیلدها آزاد است.
