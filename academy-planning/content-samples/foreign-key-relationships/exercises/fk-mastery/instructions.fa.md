# چالش تسلط: سیاست حذف در Booking

برای رزرو اتاق، مدل‌های `Guest`، `Room` و `Booking` را طراحی کن. هر Booking به یک Guest و یک Room اشاره دارد. رزرو باید حتی پس از غیرفعال‌شدن اتاق برای گزارش تاریخی باقی بماند؛ حذف Guest با رزرو فعال ممنوع است. ERD، Django Models و SQL معادل را خودت طراحی کن و درباره انتخاب رفتار حذف و Index استدلال کن.

**قبولی فنی:** Migration/Schema معتبر، رابطه‌های درست، قاعده حذف Guest و درستی چند سناریوی ثبت و حذف. **بررسی مهندسی:** توضیح استدلال و Trade-off به‌صورت Rubric؛ ممکن است چند طراحی معتبر باشند.
